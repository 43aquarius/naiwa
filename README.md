# 奶蛙桌宠 · Web 独立版

从 [43aquaris/naiwa](https://github.com/43aquaris/naiwa) 桌宠项目提取的**奶蛙 Web 桌宠**独立项目：四形态帧动画 + 点击互动 + 拖拽甩飞物理。

## 目录

| 目录 | 说明 |
|------|------|
| [`react/`](./react) | React 组件版：`NaiwaPet` 组件（零第三方 UI 依赖）+ Next.js demo |
| [`single-html/`](./single-html) | 单文件版：**一个 HTML 文件**内嵌全部素材，双击即可离线运行 |

## 玩法

- **单击奶蛙** → 微笑（9 帧 · 750ms 单次）
- **1.5 秒内连点 5 次** → 大笑（68 帧 · 5667ms 单次，音效延迟 300ms；大笑期间忽略点击）
- **拖住奶蛙甩出去** → 甩飞物理：抛物线飞行、撞壁反弹 + 挤压变形
- **控制面板** → 手动切换 待机 / 微笑 / 大笑 / 哭泣 四种形态，音效开关

## 新增功能（desktop-pet 分支）

- **入场提示**：标题与玩法提示仅在进入页面时短暂显示（7 秒后或首次点击即淡出，之后不再出现）
- **可隐藏控制面板**：点“收起 ▾”隐藏全部选项，隐藏后右下角出现 🐸 悬浮按钮可唤回
- **奶蛙大小自由调节**：80–420px 滑杆，物理常数按尺寸自动等比缩放
- **手机适配**：viewport-fit=cover 安全区、响应式面板（小屏 3 行紧凑排版）、动态地板（随面板换行/收起/旋转屏自动调整）、移动端默认尺寸 170px
- **移动设备体感**：加速度计 → 屏幕坐标系真实重力——倾斜手机奶蛙滚向低处、平放近似失重漂浮、摇晃产生冲击碰撞；自动探测 iOS/Android 符号约定差异，iOS 13+ 自动请求权限
- **撞墙笑**：处于“微笑/大笑”模式时，每次真实撞击墙壁都会重新触发当前情绪 + 音效（撞击速度阈值 + 480ms 冷却防连发）

## 四形态清单

| 形态 | 帧数 | 播放方式 | 帧率 |
|------|------|----------|------|
| idle 待机 | 58 | 循环 | 12fps |
| smile 微笑 | 9 | 单次 750ms | 12fps |
| laugh 大笑 | 68 | 单次 5667ms | 12fps |
| cry 哭泣 | 39 | 循环 | 12fps |

## 物理参数（逐项对齐原版 main.cpp）

| 参数 | 值 |
|------|-----|
| 重力 | 0.4 px/f²（按显示高度 / 249.5px 基准缩放） |
| 空气阻力 | 速度 ×0.98 / 帧 |
| 撞壁反弹 | 保留 70% 速度 |
| 停止阈值 | 落地 0.5 px/f，侧壁 3 px/f |
| 甩飞初速度 | 松手前最近 100ms 轨迹位移 / 帧数 |
| 撞壁挤压 | 上下边压缩 40% / 左右边 20%，压缩 100ms + 复原 150ms |
| 物理步长 | 固定 60Hz（requestAnimationFrame + 累加器，追帧上限 12 步） |
| 碰撞盒 | idle 首帧内容 bbox（94,30,329,657 / 518×718），避免透明留白先触壁 |

## 素材

- 雪碧图 `naiwa-pet-atlas.webp`：174 帧（58+9+68+39），8 列 row-major，259×359/帧（半分辨率化）
- 音效 `smile.mp3` / `laugh.mp3`
- 生成脚本：[`react/scripts/build_pet_sprites.py`](./react/scripts/build_pet_sprites.py)（原始帧 → 雪碧图，含非均匀拉伸对齐 laugh 画框 518×718）
